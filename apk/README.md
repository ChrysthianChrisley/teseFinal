# Aplicativo Android (.APK) - Monitor Plantar UERJ

Este diretório contém o instalador oficial do aplicativo Android compilado nativamente.

- **Arquivo:** `MonitorPlantar-v2.1.apk`
- **Compilado via:** GitHub Actions & Capacitor
- **Compatibilidade:** Android 8.0 ou superior

Para instalar no celular:
1. Baixe o arquivo `.apk` no seu celular.
2. Permita a instalação de fontes desconhecidas se solicitado.
3. Abra e conecte via Bluetooth com a tela bloqueada ou em segundo plano.
